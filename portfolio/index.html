01 / THE CONTEXT

Turning scattered study material
into searchable evidence.

THE PROBLEM

Useful explanations and examples are spread across lengthy question papers and personal notes. Finding the right passage can interrupt revision.

This project explores a practical way to search those materials by meaning, then show the passages that informed an answer. The source remains visible so learners can inspect it for themselves.

⌘
THE APPROACH

Retrieve first.
Answer with context.

Question papers and notes are indexed locally. A question retrieves relevant chunks, which are sent as context for answer generation.

Educational prototype · Not guaranteed exam guidance

KNOWN LIMITATIONS
  • OCR can misread scanned text; source passages should be checked.
  • The current PYQ ingestion targets a configured PDF and Windows-specific Tesseract path.
  • Retrieval and answer quality depend on indexed materials; evaluation is still small.
  • The interactive Python application has not been publicly deployed.
POSSIBLE IMPROVEMENTS
  • Broaden answer and citation evaluation across more topics.
  • Add configurable result counts and source filters.
  • Support selecting and managing additional source documents.
  • Harden the service for public hosting if deployment proceeds.
